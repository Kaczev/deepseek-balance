### 现在的画面是什么

圆角半透明蓝色面板，里面有三样东西：

1. **左上角一行小字**——标题兼状态行。正常时是「deepseek 余额」；没设密钥时是「未找到 DEEPSEEK_API_KEY」；没网时是「无法连接」。状态变了文字就换，不只靠颜色编码。
2. **中间一个大数字**——余额，两位小数，币种符号在前（`¥100.00`）。**读不到时显示 `--.--`，绝不显示 `0.00`**。
3. 中间还有个白色方块在走——那是"帧循环还活着"的证据，D 阶段的曲线会取代它。

带 `--debug` 时左上角多一层淡黄色文字，那是**调试浮层**：显示状态机当前判断、余额、情形编号、样本数、有没有 Key、窗口有没有焦点。浮层是**眼睛**，不是产品界面。

### 调试开关

```
--debug              显示调试浮层
--scenario=N         选情形（0 平稳 1 快速 2 余额偏低 3 充值 4 归零
                               5 不可用 6 连不上 7 旧数据 8 时钟跳变）
--speed=N            加速内部时间（快速看长期行为）
--selftest-b         金额解析与状态机自检，写 build\selftest.log
--export-frame=N     离屏导一帧到 PNG（用同一份绘制代码），然后退出
--out=名字.png       配合 --export-frame 指定输出
```

运行中按 `F1`..`F9` 切换情形、`R` 触发充值跳变、`C` 触发时钟跳变。

### 怎么跑

```
build.bat       构建（双击即可）
run.bat         看一眼（面板出现 15 秒）
run-long.bat    一直显示，直到你关掉那个 cmd 窗口
```

**当前还没有关闭交互**：三击销毁在 F 阶段才做。现在要结束它，用任务管理器结束 `dshb.exe`（或关掉 `run-long.bat` 的 cmd 窗口）。

### 关于日志

`build\selftest.log` 是诊断日志（每次运行追加）。它**不写 stdout**——这个程序是 GUI 子系统，没有控制台，往 stdout 写等于丢掉。

数据与配置落在 `%LOCALAPPDATA%\deepseek-balance\`。

构建前提：本机已装 VS Build Tools（MSVC 14.51 + Windows SDK 10.0.26100）。**`build.bat` 里不能出现任何 `set PATH=`**——那会静默丢掉 MSVC 工具链，然后 cmake 报找不到编译器。

### 运行需要的东西

密钥从环境变量 `DEEPSEEK_API_KEY` 读取，只在内存里用，不落盘。尚未接入真实接口（当前是骨架，还没有数据管道）。
