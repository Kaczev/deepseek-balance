### 觉得窗口太大？

物理像素——**像素数翻倍，物理尺寸与设计一致**。如果这仍然偏大，直接拧旋钮：

```

build\dshb.exe --roll=loop --ui-scale=0.6    面板 378x155 物理像素
build\dshb.exe --roll=loop --ui-scale=0.75   面板 473x194 物理像素
```

或双击 `run-roll.bat`，它会让你选。**选定之后我把这个值写成默认值。**
